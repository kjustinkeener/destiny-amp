# Destiny-AMP

A native desktop music player with a two-deck DJ-style audio engine, genre-aware
library organization, and an optional artist database for genre/similarity lookups.

## Download

Grab the latest release from the [Releases](https://github.com/kjustinkeener/destiny-amp/releases)
page:

- `destiny-installer.exe`: installer (recommended)
- `destiny.exe` / `tidystax.exe`: standalone binaries (portable use)
- `genres.db`: curated genre vocabulary (bundled by the installer)
- `artists.db.gz`: optional artist database (genre/similarity data for a large
  artist catalog), downloaded and decompressed on demand, not required to run
  the app

Each asset ships with a `.minisig` signature. `update.json` describes the
current release for the app's built-in updater.

## Apps

- **Destiny**: the player. Two-deck playback, crossfading, library browsing
  by genre.
- **TidyStax**: a companion tool for curating and cleaning up a music
  library (tagging, duplicate detection, genre triage).
